# 🚀 FastJoin

> **A modern Placement & Internship Management Platform built with Next.js, TypeScript, Prisma, PostgreSQL, and Auth.js.**

FastJoin is a full-stack web application designed to simplify the placement and internship process for students, recruiters, and administrators. The platform aims to provide a seamless experience for job posting, applications, and application tracking.

> 🚧 **Project Status:** Active Development

---

## ✨ Features

### 👨‍🎓 Student
- Secure Authentication
- Personalized Dashboard
- Browse Jobs & Internships
- Save Jobs
- Apply for Jobs
- Track Application Status
- Resume Upload *(Upcoming)*

### 🏢 Recruiter
- Secure Authentication
- Recruiter Dashboard
- Create Job Posts
- Edit & Manage Jobs
- Open / Close Applications
- View Applicants *(Upcoming)*

### 👨‍💼 Admin
- Manage Users
- Manage Recruiters
- Manage Jobs
- Platform Monitoring

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/abhiynar2804/fastjoin.git
```

### Navigate to the project

```bash
cd fastjoin
```

### Install dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file and add:

```env
DATABASE_URL=
AUTH_SECRET=
```

### Run the development server

```bash
npm run dev
```
